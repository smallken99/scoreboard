# 榮譽計分板 🏆

基於 **React.js** 與 **Tailwind CSS** 開發的雙分頁純數字計分板。

🌐 **線上使用網址**：[https://family-scoreboard.pages.dev](https://family-scoreboard.pages.dev)

## ✨ 特色功能

1. **姓名自訂管理介面**：
   - 不寫死任何姓名，首次進入時可由家長自訂輸入 2 位小朋友的姓名（例如：「黃辰軒」與「黃巧蔓」）。
   - 隨時點擊右上角「管理」按鈕修改姓名或重設歸零分數。
2. **2 個專屬 TAB 分開計分**：
   - 依據兩位姓名自動建立 2 個獨立 Tab 分頁。
   - 點擊 Tab 即時切換，分數各自獨立儲存。
3. **極簡純數字罐頭快捷鍵（無事由、無理由）**：
   - **加分**：`+1`、`+5`、`+10`
   - **減分**：`-1`、`-5`、`-10`
   - 點擊直接計算，不跳任何多餘彈窗，反應極快。
4. **手動自訂分數輸入**：
   - 輸入任意自訂數字，一鍵「➕ 加分」或「➖ 減分」。
5. **歷史流水帳與撤銷**：
   - 清楚記錄每次異動時間與點數變動。
   - 提供「↩️ 撤銷上一筆操作」及單筆刪除功能。
6. **瀏覽器即時保存**：
   - 所有資料自動儲存於瀏覽器 `localStorage`，關閉視窗或重新整理皆不會遺失。

---

## 🧪 自動化單元測試

專案內建核心計分邏輯驗證腳本，您可在終端機執行：
```powershell
node test.js
```
將會自動驗證：
- 罐頭分數 `+1, +5, +10` 與 `-1, -5, -10` 計算
- 手動自訂分數計算
- 撤銷上一步 (Undo) 分數回調
- 刪除歷史明細時分數回推
- 兩位小朋友雙 Tab 資料獨立性

---

## 🚀 如何開啟使用

直接在檔案總管中雙擊 `index.html`，即可在任何瀏覽器（Chrome、Edge、Safari、手機瀏覽器）直接開啟使用，無需安裝 Node.js 或建置環境。
